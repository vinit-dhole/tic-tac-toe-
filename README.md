#Tic Tac Toe Game
A responsive Tic Tac Toe game built using HTML,CSS and JavaScript.

##Features
-Two player gameplay
-X and O turn system
-Win detection
-Draw detection
-Score Tracking
-Reset Game Functionality
-New game Functionality
-Winning-cell highlighting
-Responsive design

##Technologies Used
-HTML5
-CSS3
-JavaScript

##What I Learned
Through this project, I practiced:
-DOM manipulation
-Event listerners
-JavaScript functions
-Arrays and loops
-Conditional Logic
-Game state management
-Responsive web design
